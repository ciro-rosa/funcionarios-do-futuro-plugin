TERMOS DE ENGENHARIA DE PROMPT - BASE DE CONHECIMENTO

=== ESTRUTURA BÁSICA DO PROMPT ===

ORDEM DE IMPORTÂNCIA:
1. Sujeito principal (modelo de referência)
2. Ação/pose/expressão
3. Ambiente/cenário
4. Iluminação
5. Estilo/atmosfera
6. Qualidade técnica
7. Termos de refinamento

FORMATO RECOMENDADO:
[MODELO], [AÇÃO/POSE], [AMBIENTE], [ILUMINAÇÃO], [ESTILO], [QUALIDADE], [REFINAMENTOS]

EXEMPLO DE ESTRUTURA:
"[NOME_MODELO], sitting confidently in a modern office, natural window lighting, professional business style, ultra-realistic, 8K UHD, shot with Canon EOS R5"

=== CONTROLE DE PESO E ÊNFASE ===

SISTEMA DE PARÊNTESES:
- (termo): ênfase leve (peso 1.1)
- ((termo)): ênfase média (peso 1.21)
- (((termo))): ênfase forte (peso 1.33)
- (termo:1.2): ênfase específica (peso 1.2)
- (termo:0.8): redução de peso (peso 0.8)

SISTEMA DE COLCHETES:
- [termo]: redução leve (peso 0.9)
- [[termo]]: redução média (peso 0.81)
- [[[termo]]]: redução forte (peso 0.73)

EXEMPLOS PRÁTICOS:
- ((ultra-realistic)): máxima ênfase no realismo
- (cinematic lighting:1.3): iluminação cinematográfica enfatizada
- [background:0.7]: fundo menos importante
- (((photorealistic))): realismo extremamente enfatizado

=== EVITAR TERMOS CONFLITANTES ===

CONFLITOS COMUNS:
- "realistic" + "cartoon": realista vs desenho animado
- "professional" + "amateur": profissional vs amador
- "sharp" + "blurry": nítido vs desfocado
- "bright" + "dark": brilhante vs escuro
- "modern" + "vintage": moderno vs vintage
- "minimalist" + "cluttered": minimalista vs bagunçado
- "natural" + "artificial": natural vs artificial
- "candid" + "posed": espontâneo vs posado

SOLUÇÕES PARA CONFLITOS:
- Use termos específicos: "soft natural lighting" em vez de "natural artificial"
- Contextualize: "vintage-inspired modern design"
- Priorize: escolha o termo mais importante
- Combine harmoniosamente: "professionally candid"

=== TÉCNICAS AVANÇADAS ===

PROMPT BLENDING:
- Use vírgulas para separar conceitos
- Use "and" para conectar elementos relacionados
- Use "with" para adicionar detalhes
- Use "in the style of" para referências artísticas

NEGATIVE PROMPTS (O QUE EVITAR):
- low quality, blurry, pixelated
- amateur, unprofessional, snapshot
- distorted, deformed, ugly
- overexposed, underexposed, poor lighting
- generic, boring, cliché
- artificial, fake, unrealistic
- cluttered, messy, chaotic
- low resolution, compressed, artifacts

PROMPT PROGRESSION:
1. Conceito básico: sujeito + ação
2. Adicionar contexto: ambiente + iluminação
3. Refinar estilo: atmosfera + referências
4. Otimizar qualidade: termos técnicos + artistas
5. Ajustar peso: parênteses e colchetes
