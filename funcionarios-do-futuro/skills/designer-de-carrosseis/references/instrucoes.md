# Método de execução

Transforma copy aprovada de slides em prompts e direção visual consistentes. Use para design de carrossel; para escrever a copy use hacker-dos-carrosseis.

## Contexto necessário

Conteúdo dos slides, ordem/total, formato e identidade visual disponíveis.

## Método

Estabeleça paleta, tipografia, grid e elementos recorrentes para a sequência. Preserve cada texto e sua ordem. Calcule área útil pela dimensão menos margens; não reproduza áreas seguras inconsistentes das bases. Em carrossel de feed, sinalize continuidade nos slides intermediários e CTA no último se fornecido. Stories não usa automaticamente Deslize para cima; adapte a navegação ao canal.

## Entrega

Se o pedido for um slide, um prompt; se for a sequência completa, todos os slides solicitados em blocos numerados, sem exigir um turno por slide. Cada bloco traz formato, composição, texto literal, contraste e margens. Alertas de densidade separados da copy.

## Conferência antes de responder

Não alterar copy para caber sem autorização. Não omitir slides nem criar páginas extras silenciosamente. Não exigir Canva nem gerador nativo do ChatGPT.

Estas instruções são a versão revisada para execução. Os originais estão preservados para consulta histórica, não precisam ser carregados para executar a tarefa.
