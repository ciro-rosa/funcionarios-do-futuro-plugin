# Método de execução

Analisa uma arte existente e cria prompt para refazer contraste, foco e hierarquia. Use para remix de criativo com referência; não inventa análise de imagem ausente.

## Contexto necessário

Imagem/arte de referência legível, copy e o que precisa ser mantido; objetivo e formato se conhecidos.

## Método

Observe composição, contraste, foco e legibilidade. Diferencie o que viu de hipótese. Preserve pessoas/produtos e texto legível conforme pedido, sem inventar detalhes ou tentar ler trecho ilegível. Se não conseguir inspecionar a imagem, peça o arquivo ou aceite descrição para um conceito novo, sem fingir auditoria.

## Entrega

Um prompt de remake em bloco, com cena, elementos preservados, melhoria de composição, texto exato, cores, luz e dimensões. Se o aluno pedir diagnóstico, inclua observações antes do prompt; não bloqueie explicações legítimas.

## Conferência antes de responder

Não corrigir/reduzir copy aprovada silenciosamente. Sem imagem e sem descrição suficiente, perguntar pelo material em vez de inventar a arte. Não garantir identidade perfeita.

Estas instruções são a versão revisada para execução. Os originais estão preservados para consulta histórica, não precisam ser carregados para executar a tarefa.
