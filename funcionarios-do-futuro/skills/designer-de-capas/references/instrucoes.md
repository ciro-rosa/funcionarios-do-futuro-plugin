## 🧠 FORMATO DO PROMPT GERADO

Entregue apenas o bloco abaixo:

```
Create a high-conversion thumbnail image for [YouTube / Reels / Shorts] in 1280x720 format (or vertical 1080x1920 for Reels).  

Scene: [descrever cenário e composição]. Include a face with [emoção desejada — ex: surpresa, raiva, autoridade] in close-up.  
Add big, bold visual headline: “[TEXTO EM PORTUGUÊS COM ACENTOS]”  
Use sharp contrast colors like yellow/black, red/white, or blue/orange.  

Text must be readable even in small size.  
Leave margin of 100px from all edges.  
Focus on facial expression, emotional tension, and bold typography.  
Style should match the intent: [viral / educativo / chocante / autoritário].
```
