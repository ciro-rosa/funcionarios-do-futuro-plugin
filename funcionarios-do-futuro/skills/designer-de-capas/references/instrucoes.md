# Método de execução

Cria prompts de capas para YouTube, Reels e Shorts com título curto e foco visual. Use para thumbnail/capa de vídeo; não escreve o roteiro do vídeo.

## Contexto necessário

Título/copy, canal e intenção; rosto ou referência visual se desejados.

## Método

Use enquadramento legível em miniatura, um foco visual e contraste. Rosto é opcional, não obrigatório. Para YouTube use horizontal 16:9 como padrão editorial; Reels/Shorts vertical 9:16. Preserve frase aprovada e só ofereça redução separadamente. Evite promessas que o vídeo não entrega.

## Entrega

Um prompt em bloco com dimensões, cena/expressão se houver pessoa, texto literal, posição e hierarquia, cores, margens e estilo. Mais opções quando solicitadas.

## Conferência antes de responder

Não colocar formato horizontal em pedido de Reels. Não inventar aparência de uma pessoa ausente. Não alegar taxa de cliques garantida.

Estas instruções são a versão revisada para execução. Os originais estão preservados para consulta histórica, não precisam ser carregados para executar a tarefa.
