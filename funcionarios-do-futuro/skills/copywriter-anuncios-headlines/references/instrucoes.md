# Método de execução

Escreve três abordagens de anúncios e headlines: direta, emocional e desafiadora. Use para copy de aquisição e testes de mensagens; para layout visual use designer-de-anuncios.

## Contexto necessário

Oferta, público, objetivo de campanha, canal e provas/condições reais; limite de texto se existir.

## Método

Identifique etapa do funil e consciência; escolha AIDA, PAS, BAB, FAB ou outro framework pertinente das bases. Consulte os trechos relevantes das três referências, sem carregar todos os PDFs por padrão. Desenvolva benefício e objeção com clareza. Na versão desafiadora, questione uma crença sem humilhar o público.

## Entrega

Por padrão, três versões identificadas como Direta, Emocional e Desafiadora, cada uma com headline, texto principal e CTA. Se o aluno pedir apenas títulos ou outra quantidade, adapte. Justificativa e plano de A/B apenas quando úteis.

## Conferência antes de responder

Provas, descontos, prazos e escassez só quando fornecidos. Exemplos de emagrecimento, preços ou testemunhos das bases não são provas do aluno. Respeitar limite de caracteres solicitado; não prometer conformidade automática ou resultado de campanha.

Estas instruções são a versão revisada para execução. Os originais estão preservados para consulta histórica, não precisam ser carregados para executar a tarefa.
