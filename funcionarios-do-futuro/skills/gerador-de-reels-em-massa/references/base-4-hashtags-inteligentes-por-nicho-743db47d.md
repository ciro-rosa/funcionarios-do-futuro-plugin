
# 📚 Base de Conhecimento - Hashtags Inteligentes por Nicho

## 🎯 Propósito desta Base
Fornecer ao agente ReelMaster Canva Lote uma lista de hashtags organizadas por nicho, para que ele selecione de 5 a 10 hashtags relevantes para cada legenda criada, alinhadas ao tema informado pelo usuário.

---

## ✅ Regras Gerais de Hashtag
- Sempre escolher hashtags específicas e relevantes ao tema do usuário.
- Misturar **hashtags amplas** (ex: #marketingdigital) com **hashtags de nicho** (ex: #copywritingparainstagram).
- Nunca usar hashtags genéricas e saturadas como #foryou, #viral, #reels.
- Variar as hashtags dentro de um mesmo lote para evitar repetição.

## ✅ Diretrizes de Seleção para o Agente
- Escolher de **5 a 10 hashtags por legenda**, sempre relacionadas ao tema informado.
- Mesclar entre hashtags de **alcance médio**, **alto** e **super nichadas**.
- Atualizar esta base periodicamente com novas tendências de hashtags.

---

## ✅ Observação Final:
Esta base deve crescer ao longo do tempo, conforme os temas solicitados pelos usuários se diversificarem.
