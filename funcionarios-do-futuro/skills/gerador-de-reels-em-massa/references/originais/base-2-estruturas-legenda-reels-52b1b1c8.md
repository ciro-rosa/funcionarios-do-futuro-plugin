
# 📚 Base de Conhecimento - Estruturas de Legenda para Reels

## 🎯 Propósito desta Base
Fornecer ao agente ReelMaster Canva Lote um repertório de estruturas de construção de legendas, para garantir que cada post tenha um conteúdo de valor, fluido, com início, meio, fim e CTA final.

---

## ✅ Estruturas de Legenda Permitidas

### 1. Problema → Solução → CTA
**Uso:** Quando o objetivo é resolver uma dor específica.
**Exemplo de Fluxo Interno (não visível no output):**
- Descrever um problema que o público enfrenta
- Oferecer uma solução ou dica prática
- Finalizar com um CTA direto

### 2. Dica Rápida → Explicação → CTA
**Uso:** Para compartilhar hacks ou truques rápidos.
**Fluxo Interno:**
- Dar a dica de forma breve
- Explicar como aplicar
- Fechar com CTA

### 3. Mito → Verdade → CTA
**Uso:** Para desconstruir crenças erradas do público.
**Fluxo Interno:**
- Apontar o mito comum
- Apresentar a verdade
- CTA chamando para ação

### 4. Pergunta Provocativa → Resposta → CTA
**Uso:** Estimular a curiosidade e a interação.
**Fluxo Interno:**
- Fazer uma pergunta impactante
- Trazer a resposta ou explicação
- CTA de engajamento

### 5. Benefício → Como Fazer → CTA
**Uso:** Para mostrar ganho prático ao público.
**Fluxo Interno:**
- Apresentar o benefício esperado
- Ensinar o passo a passo
- Fechar com CTA

### 6. Erro → Correção → CTA
**Uso:** Mostrar o que o público está fazendo de errado e como ajustar.
**Fluxo Interno:**
- Apontar o erro comum
- Ensinar a forma correta
- CTA para ação

---

## ✅ Diretrizes de Redação da Legenda

- Linguagem natural, humana e fluída
- Nunca usar marcações tipo “Problema:”, “Solução:”, etc no texto final
- Tamanho: no mínimo 3 a 5 linhas por legenda
- Sempre finalizar com um CTA claro
- Adaptar o conteúdo ao tema e tom escolhidos pelo usuário

---

## ✅ Exemplos de CTA para Fechamento de Legenda

- Salve esse post!
- Compartilhe com alguém que precisa saber disso
- Comente o que achou
- Me conta sua opinião!
- Teste e me conte depois!
- Marca alguém que precisa dessa dica

---

## ✅ Observação Final:
O agente pode alternar livremente entre essas estruturas para gerar diversidade nos lotes. Novos formatos podem ser incluídos futuramente.
