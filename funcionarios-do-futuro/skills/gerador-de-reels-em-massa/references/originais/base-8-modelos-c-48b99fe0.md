
# 📚 Base de Conhecimento - Modelos de Calendário Editorial (Opcional Enterprise)

## 🎯 Propósito desta Base
Fornecer ao agente ReelMaster Canva Lote uma referência de **distribuição estratégica de temas ao longo da semana ou do mês**, caso o usuário deseje que o agente sugira um calendário editorial para organizar os lotes de Reels.

---

## ✅ Estruturas de Calendário Sugeridas

### Exemplo 1: Sequência Semanal de Conteúdo (7 Dias)
| Dia        | Tipo de Conteúdo              |
|----------- |------------------------------ |
| Segunda    | Dica prática (Educativo)      |
| Terça      | Insight ou Curiosidade        |
| Quarta     | Erro Comum e Como Corrigir    |
| Quinta     | Benefício ou Resultado Esperado |
| Sexta      | Pergunta para Engajamento     |
| Sábado     | Bastidores ou Conteúdo Pessoal |
| Domingo    | Recapitulação ou Motivacional |

---

### Exemplo 2: Ciclo de Conteúdo Mensal (4 Semanas)
| Semana | Foco Principal                     |
|------  |----------------------------------- |
| 1ª     | Problemas e Dores do Público       |
| 2ª     | Dicas e Hacks para Soluções        |
| 3ª     | Prova Social, Estudos de Caso, Exemplos |
| 4ª     | CTA Fortes e Direcionamento para Vendas |

---

## ✅ Diretrizes para o Agente ao Aplicar um Calendário
- Só aplicar o calendário se o usuário solicitar explicitamente.
- O agente deve adaptar o calendário ao **tema e tom informados pelo usuário**.
- O usuário pode pedir um lote de Reels por dia, por semana ou por tipo de conteúdo.

---

## ✅ Exemplos de Comandos que Ativam o Calendário
- "Quero um calendário editorial para o mês"
- "Gere 7 Reels seguindo uma estrutura semanal de conteúdo"
- "Me sugira uma sequência estratégica de temas para os próximos 7 dias"

---

## ✅ Observação Final:
Esta base é opcional e deve ser usada apenas em cenários enterprise, quando o usuário busca planejamento estratégico além da simples criação de lotes de Reels.
