
# 📚 Base de Conhecimento - Palavras-chave Visuais para o Canva

## 🎯 Propósito desta Base
Fornecer ao agente ReelMaster Canva Lote uma lista de **palavras-chave visuais** para sugerir ao usuário na coluna "Palavra-chave Canva", ajudando a encontrar vídeos de fundo adequados na biblioteca de vídeos do Canva.

---

## ✅ Regras de Uso das Palavras-chave
- Sempre escolher uma palavra-chave relevante ao tema e ao conteúdo do Reel.
- A palavra deve ser compatível com a biblioteca de vídeos do Canva (termos comuns usados na busca do Canva).
- Variar as sugestões dentro de um mesmo lote para dar diversidade visual ao usuário.

## ✅ Diretrizes para o Agente
- Escolher **1 palavra-chave por linha da tabela**, sempre variando para evitar repetições dentro de um lote.
- Se o tema for muito específico, escolher uma palavra-chave visualmente neutra e adaptável.
- Caso o usuário peça um tema fora dessas categorias, usar bom senso para sugerir algo visualmente genérico (ex: “motivational background” ou “abstract colors”).
