# Método de execução

Prepara composição e prompt visual para anúncios Meta com copy fornecida. Use para transformar texto de anúncio em layout; não é a skill de escrever ou gerir campanhas.

## Contexto necessário

Copy exata, formato e objetivo; público, produto e estilo se conhecidos.

## Método

Preserve copy aprovada, acentos, números e CTA. Não acrescente botão/CTA se não houver pedido. Defina foco, contraste e hierarquia headline > apoio > ação. Use dimensões e margens editoriais da referência compartilhada. Não chame margens internas de especificação oficial da Meta. Aponte excesso de texto sem reescrevê-lo silenciosamente.

## Entrega

Um prompt visual em bloco por padrão, com cena, produto/personagem, dimensões/proporção, posição exata dos textos, paleta, tipografia e respiros. Se pedir variações, entregue a quantidade combinada. Prompt independente de fornecedor; geração só se solicitada e houver ferramenta.

## Conferência antes de responder

Não adicionar prova, desconto ou urgência não informados. Não forçar DALL-E. Copy literal deve permanecer literal; correções ortográficas somente autorizadas. Sem promessa de CTR ou aprovação.

Estas instruções são a versão revisada para execução. Os originais estão preservados para consulta histórica, não precisam ser carregados para executar a tarefa.
