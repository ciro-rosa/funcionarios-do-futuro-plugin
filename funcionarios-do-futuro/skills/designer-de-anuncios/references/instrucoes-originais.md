## 🧠 ESTRATÉGIAS POR OBJETIVO DE CAMPANHA

**Reconhecimento**
- Contraste visual máximo
- Elementos disruptivos que capturam atenção
- Simplicidade visual com mensagem memorável
- Paletas de cores vibrantes

**Consideração**
- Demonstração clara de valor/benefício
- Visualização do problema/solução
- Elementos que comunicam autoridade/confiança
- Composição que guia o olhar para pontos-chave

**Conversão**
- CTA destacado com contraste forte
- Elementos que criam urgência/escassez visual
- Hierarquia visual que termina no botão de ação
- Estética direta focada em resultado imediato

---

## 📱 ESPECIFICAÇÕES POR FORMATO

**Feed Quadrado (1080x1080px)**
- Área segura central: 880x880px
- Margem obrigatória: 100px em todos os lados
- Composição centralizada ou em grade

**Feed Retrato (1080x1350px)**
- Área segura central: 880x1150px
- Margem obrigatória: 100px laterais, 100px superior/inferior
- Layout vertical que guia o olhar de cima para baixo

**Stories/Reels (1080x1920px)**
- Área segura central: 880x1520px
- Margem obrigatória: 100px laterais, 200px superior/inferior
- Elementos essenciais longe das bordas (área de UI do app)

**Carrossel**
- Dimensões do formato principal selecionado
- Design que incentiva deslizar para o próximo
- Numeração visual ou elementos de continuidade

## 💡 PRINCÍPIOS DE PSICOLOGIA VISUAL

Incorpore estes gatilhos de conversão:

**Urgência/Escassez**
- Elementos visuais de tempo limitado
- Simbolismo de exclusividade/raridade

**Prova Social**
- Elementos que sugerem aprovação coletiva
- Iconografia de números/multidão (quando apropriado)

**Autoridade**
- Elementos que comunicam expertise/credibilidade
- Simbolismo de confiança/segurança

**Reciprocidade**
- Visual que comunica valor entregue antes da compra
- Elementos que sugerem "presente/benefício imediato"
