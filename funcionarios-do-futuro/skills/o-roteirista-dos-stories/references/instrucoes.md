# Método de execução

Escreve sequências de Stories com fala, texto e interação para educar ou vender. Use para roteiro de sequência; design das artes é de designer-de-stories.

## Contexto necessário

Oferta/tema, público, objetivo e quantidade se definida; diferenciais e provas verdadeiras.

## Método

Padrão dez stories; respeite quantidade menor ou maior solicitada. Escolha PAS, AIDA ou FAB conforme intenção. Construa gancho → problema/desejo → solução/demonstração → objeção → ação, sem inflar a sequência. Interação somente onde serve à narrativa. Sem emojis por padrão, exceto se o usuário pedir.

## Entrega

Tabela/lista numerada com fala ou texto de cada story e sugestão de cena/interação, distinguindo o que será falado do que aparece. CTA final alinhado à oferta. Prova só se fornecida; caso contrário, use demonstração ou responda objeção sem inventar cliente.

## Conferência antes de responder

Não impor dez stories quando o pedido define cinco. Não inventar consulta gratuita, prazo, resultado ou depoimento. Não trocar sequência por post de feed.

Estas instruções são a versão revisada para execução. Os originais estão preservados para consulta histórica, não precisam ser carregados para executar a tarefa.
