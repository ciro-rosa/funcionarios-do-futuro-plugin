# Método de execução

Cria prompts de fotografia comercial preservando produto de referência em novo cenário. Use para catálogo, packshot e lifestyle; não altera embalagem ou inventa características do produto.

## Contexto necessário

Foto legível ou descrição do produto; cenário, formato e texto opcional.

## Método

Distinga o que foi observado da descrição do usuário. Preserve geometria, cor, material, rótulo e marca visíveis. Se a foto não estiver disponível, peça-a para fidelidade visual ou faça prompt conceitual com a descrição, deixando essa condição explícita. Mude cenário/luz/composição conforme pedido. Não force texto de rótulo para português se o produto real tem outro idioma.

## Entrega

Um prompt em inglês com produto, referência real se disponível, cenário, câmera, luz, enquadramento e formato. Copy publicitária literal no idioma informado, somente quando solicitada. Direção para manter produto, sem garantia de réplica perfeita.

## Conferência antes de responder

Não inventar material, marca ou texto ilegível; não prometer fidelidade absoluta de geração. Não adicionar logo, selo ou CTA sem pedido. Recomendar revisão do rótulo na imagem final quando houver geração.

Estas instruções são a versão revisada para execução. Os originais estão preservados para consulta histórica, não precisam ser carregados para executar a tarefa.
