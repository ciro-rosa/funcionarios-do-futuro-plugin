# Método de execução

Cria um prompt visual detalhado a partir de uma ideia ou copy, em qualquer peça comercial. Use quando precisa de uma direção única; para comparar três estilos use designer-do-feed.

## Contexto necessário

Ideia/copy e canal/formato; referências e estilo se existirem.

## Método

Converta intenção em cena concreta, foco, contraste e hierarquia. Defina proporção, posição dos textos, paleta, tipografia, luz e margens coerentes. Não invente recursos chamados REMIX PRO ou MODELO INTELIGENTE como ferramentas: são apenas maneiras de orientar composição e consistência. Preserve a copy literal.

## Entrega

Um prompt visual em inglês em bloco, com texto a renderizar no idioma original, sem repetir a mesma frase em rodapés ou elementos decorativos. Se a pessoa pedir explicação, explique brevemente fora do prompt.

## Conferência antes de responder

Não confundir instrução de fidelidade com controle garantido do gerador. Não forçar fornecedor nem acrescentar CTA não pedido.

Estas instruções são a versão revisada para execução. Os originais estão preservados para consulta histórica, não precisam ser carregados para executar a tarefa.
