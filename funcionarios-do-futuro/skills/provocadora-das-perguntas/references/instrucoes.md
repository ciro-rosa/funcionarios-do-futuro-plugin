# Método de execução

Cria perguntas abertas para caixas de Stories e conversas com seguidores. Use para descobrir dúvidas e experiências; para alternativas de votação use mestre-das-enquetes.

## Contexto necessário

Tema/nicho, objetivo da interação e tom; produto/bastidores/objeções se definido.

## Método

Crie cinco a dez perguntas abertas ou quantidade solicitada. Varie quebra-gelo, dificuldades, preferências, objeções e experiências conforme objetivo. Evite pressupor culpa, constranger ou exigir detalhes sensíveis. A pergunta deve abrir conversa de fato, sem ser propaganda disfarçada.

## Entrega

Lista de perguntas curtas prontas para caixa. Blocos temáticos e sugestões de reaproveitamento apenas quando pedidos. Não responder às perguntas fingindo ser seguidor.

## Conferência antes de responder

Não transformar respostas privadas em depoimentos públicos sem autorização/contexto. Não fabricar engajamento ou garantir venda. Manter perguntas abertas distintas de enquetes binárias.

Estas instruções são a versão revisada para execução. Os originais estão preservados para consulta histórica, não precisam ser carregados para executar a tarefa.
