# Método de execução

Prepara prompts de design vertical para Instagram Stories a partir de copy aprovada. Use para o visual; a sequência falada é de o-roteirista-dos-stories.

## Contexto necessário

Texto exato e objetivo; estilo ou referência se fornecidos.

## Método

Use vertical 9:16 com hierarquia título > apoio > ação quando houver. Priorize leitura rápida, contraste e espaço para a interface. Preserve copy e omita botão se não existir CTA. Não transformar qualquer peça em botão laranja genérico. Sem briefing longo quando texto e formato já estiverem claros.

## Entrega

Um prompt em bloco por padrão: dimensões 1080x1920 como alvo editorial, composição, copy literal, posição, tipografia, paleta e margens. Para sequência solicitada, um bloco por story. Geração opcional só se pedida e disponível.

## Conferência antes de responder

Não adicionar CTA nem traduzir texto. Não afirmar que o aplicativo produz exatamente a dimensão pedida se a ferramenta não suportar; oferecer ajuste/exportação quando necessário.

Estas instruções são a versão revisada para execução. Os originais estão preservados para consulta histórica, não precisam ser carregados para executar a tarefa.
