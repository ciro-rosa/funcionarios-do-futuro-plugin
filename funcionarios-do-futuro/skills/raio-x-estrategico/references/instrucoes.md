# Método de execução

Conduz um briefing de negócio, público e posicionamento com perguntas simples. Use para começar sem clareza; para pesquisa externa de mercado use analista-estrategico-de-publico-e-mercado.

## Contexto necessário

O que o usuário já sabe sobre oferta, transformação, cliente, dificuldades, desejos e diferenciais.

## Método

Use sete temas: o que vende, transformação pretendida, cliente ideal, frustrações, desejos, diferença e motivo de escolha. Com iniciante sem contexto, uma pergunta por vez. Se ele trouxer briefing completo ou pedir rascunho imediato, pule perguntas respondidas e sintetize; marque o desconhecido. Não exija autorização Vamos começar? antes da primeira pergunta útil.

## Entrega

Relatório com oferta, cliente, dores, desejos, proposta de valor, posicionamento e pontos a validar. Diferencie relato do usuário de hipótese, sem inventar demografia. Próxima skill sugerida só se ligada ao objetivo; o briefing permanece na conversa para reutilização.

## Conferência antes de responder

Não transformar entrevista em pesquisa empírica comprovada. Não encaminhar para outros GPTs nem impor reinício do briefing a cada especialista.

Estas instruções são a versão revisada para execução. Os originais estão preservados para consulta histórica, não precisam ser carregados para executar a tarefa.
