# Catálogo dos Funcionários do Futuro

Escolha a skill pelo resultado desejado. Reaproveite o briefing da conversa entre as etapas.

Sora e VEO 3 separados foram excluídos por orientação do autor; V.I.S.I.O.N cobre essas funções.

| Especialista | Função | Skill |
|---|---|---|
| Analista Estratégico de Público e Mercado | Pesquisa público, concorrência, consciência de compra e oportunidades de oferta. Use para análise de mercado e diagnóstico de oferta; para descobrir o negócio do zero, use raio-x-estrategico. | [analista-estrategico-de-publico-e-mercado](../skills/analista-estrategico-de-publico-e-mercado/SKILL.md) |

| O Consultor de Perfil | Audita a vitrine do perfil de Instagram: nome, bio, link, foto e destaques. Use com print ou transcrição; não infere métricas de desempenho a partir do perfil. | [consultora-de-perfil](../skills/consultora-de-perfil/SKILL.md) |
| Copyriter Anúncios & Headlines 2.0 | Escreve três abordagens de anúncios e headlines: direta, emocional e desafiadora. Use para copy de aquisição e testes de mensagens; para layout visual use designer-de-anuncios. | [copywriter-anuncios-headlines](../skills/copywriter-anuncios-headlines/SKILL.md) |
| GPT Copywriter Profissional \| Copy para Vendas | Cria copy completa adaptada ao canal, público e jornada: páginas, e-mails, posts e roteiros. Use para peças e revisões de copy; anúncios em três ângulos têm skill específica. | [copywriter-profissional](../skills/copywriter-profissional/SKILL.md) |
| 💸 O Criador de Posts que Vendem | Escreve posts comerciais de Instagram com gancho, benefício e CTA. Use para transformar oferta em um post simples pronto; legendas de uma peça existente cabem a musa-das-legendas. | [criador-de-posts](../skills/criador-de-posts/SKILL.md) |
| 🎨 Designer Mestre | Cria um prompt visual detalhado a partir de uma ideia ou copy, em qualquer peça comercial. Use quando precisa de uma direção única; para comparar três estilos use designer-do-feed. | [designer-mestre](../skills/designer-mestre/SKILL.md) |
| Designer Recriador | Analisa uma arte existente e cria prompt para refazer contraste, foco e hierarquia. Use para remix de criativo com referência; não inventa análise de imagem ausente. | [designer-recriador](../skills/designer-recriador/SKILL.md) |
| Designer de Anúncios 2.0 | Prepara composição e prompt visual para anúncios Meta com copy fornecida. Use para transformar texto de anúncio em layout; não é a skill de escrever ou gerir campanhas. | [designer-de-anuncios](../skills/designer-de-anuncios/SKILL.md) |
| Designer de Capas | Cria prompts de capas para YouTube, Reels e Shorts com título curto e foco visual. Use para thumbnail/capa de vídeo; não escreve o roteiro do vídeo. | [designer-de-capas](../skills/designer-de-capas/SKILL.md) |
| Designer de Carrosséis 2.0 | Transforma copy aprovada de slides em prompts e direção visual consistentes. Use para design de carrossel; para escrever a copy use hacker-dos-carrosseis. | [designer-de-carrosseis](../skills/designer-de-carrosseis/SKILL.md) |
| Designer de Produtos 2.0 | Cria prompts de fotografia comercial preservando produto de referência em novo cenário. Use para catálogo, packshot e lifestyle; não altera embalagem ou inventa características do produto. | [designer-de-produtos](../skills/designer-de-produtos/SKILL.md) |
| Quadrinhos Virais | Cria histórias em quadrinhos para carrossel, com quatro quadros por slide e continuidade de personagem. Use para narrativa ilustrada; não para carrossel fotográfico comum. | [designer-de-quadrinhos-virais](../skills/designer-de-quadrinhos-virais/SKILL.md) |
| Designer de Stories | Prepara prompts de design vertical para Instagram Stories a partir de copy aprovada. Use para o visual; a sequência falada é de o-roteirista-dos-stories. | [designer-de-stories](../skills/designer-de-stories/SKILL.md) |
| 🎨 Designer do Futuro | Oferece três direções visuais para um post de feed a partir de texto e objetivo. Use para explorar estilos; designer-mestre aprofunda uma direção visual. | [designer-do-feed](../skills/designer-do-feed/SKILL.md) |
| ELEVEN PROMPTER PRO | Prepara texto para narração com tags de entonação e pausas para ElevenLabs. Use para direção de voz mantendo as palavras do original; não gera áudio nem clona uma voz. | [eleven-prompter-pro](../skills/eleven-prompter-pro/SKILL.md) |
| Gerador de Reels em Massa | Cria lotes de ideias de Reels em tabela ou CSV para o Criar em Lote do Canva. Use para produção em massa com ganchos, legenda e termo visual; não acessa o Canva. | [gerador-de-reels-em-massa](../skills/gerador-de-reels-em-massa/SKILL.md) |
| 🧞‍♂️ O Gênio dos Reels | Escreve roteiros de Reels/TikTok com gancho, desenvolvimento, virada e CTA. Use para roteiro gravável; para lotes de ideias em tabela use gerador-de-reels-em-massa. | [genio-dos-reels](../skills/genio-dos-reels/SKILL.md) |
| 🧠 O Hacker dos Carrosséis | Escreve copy de carrossel slide a slide com gancho, desenvolvimento e CTA. Use para conteúdo de carrossel; prompts/layout dos slides são de designer-de-carrosseis. | [hacker-dos-carrosseis](../skills/hacker-dos-carrosseis/SKILL.md) |
| 🎯 O Mestre das Enquetes | Cria enquetes de Stories com pergunta e duas alternativas para entender interesses e objeções. Use para votação; perguntas abertas cabem a provocadora-das-perguntas. | [mestre-das-enquetes](../skills/mestre-das-enquetes/SKILL.md) |
| Mestre dos Clones | Cria prompts fotográficos com modelo/identidade já configurada no gerador, extraindo pose, cena e luz da referência. Use quando há token ou nome do modelo; para separar imagem de identidade e cena use vision. | [mestre-dos-clones](../skills/mestre-dos-clones/SKILL.md) |
| Mestre dos Prompts para Vídeo em JSON | Cria JSON estruturado de prompt para vídeo curto em plano único. Use quando o pedido exige JSON; ideias de cenas são de roteirista-viral-para-flow e prompt livre é de vision. | [mestre-dos-prompts-para-video-em-json](../skills/mestre-dos-prompts-para-video-em-json/SKILL.md) |
| 💃 A Musa das Legendas | Escreve legendas para imagem, vídeo ou carrossel com voz de marca e CTA natural. Use para acompanhar conteúdo já definido; não refaz a peça inteira sem pedido. | [musa-das-legendas](../skills/musa-das-legendas/SKILL.md) |
| ✍️ O Roteirista dos Stories | Escreve sequências de Stories com fala, texto e interação para educar ou vender. Use para roteiro de sequência; design das artes é de designer-de-stories. | [o-roteirista-dos-stories](../skills/o-roteirista-dos-stories/SKILL.md) |
| 📊 O Planejador das Postagens | Organiza calendário editorial por período, formato, tema, objetivo e CTA. Use para planejar uma sequência de publicações; não agenda nem publica automaticamente. | [planejador-das-postagens](../skills/planejador-das-postagens/SKILL.md) |
| 🔥 O Provocador das Perguntas | Cria perguntas abertas para caixas de Stories e conversas com seguidores. Use para descobrir dúvidas e experiências; para alternativas de votação use mestre-das-enquetes. | [provocadora-das-perguntas](../skills/provocadora-das-perguntas/SKILL.md) |
| A Rainha dos Títulos | Cria títulos e ganchos curtos para posts, carrosséis e vídeos. Use quando o entregável é a abertura/headline; não o conteúdo inteiro. | [rainha-dos-titulos](../skills/rainha-dos-titulos/SKILL.md) |
| Raio-X Estratégico | Conduz um briefing de negócio, público e posicionamento com perguntas simples. Use para começar sem clareza; para pesquisa externa de mercado use analista-estrategico-de-publico-e-mercado. | [raio-x-estrategico](../skills/raio-x-estrategico/SKILL.md) |
| Roteirista Viral para FLOW | Propõe ideias de cenas curtas para Flow/VEO com explicação e brief, sem JSON. Use para ideação audiovisual; JSON estruturado é de mestre-dos-prompts-para-video-em-json. | [roteirista-viral-para-flow](../skills/roteirista-viral-para-flow/SKILL.md) |
| Suporte 24 horas Funcionários do Futuro | Descubra qual agente usar para cada necessidade, receba recomendações personalizadas e fluxos de trabalho otimizados para suas tarefas de marketing digital. | [suporte-24-horas](../skills/suporte-24-horas/SKILL.md) |
| V.I.S.I.O.N. | Cria prompts livres de imagem/vídeo, identidade de referência e influencer fictícia. Use para direção cinematográfica e substitui os antigos Sora/VEO separados; JSON tem skill própria. | [vision](../skills/vision/SKILL.md) |
